# Security

To report a vulnerability in velauth-scan, email security@velauth.com. Please include the version (`velauth-scan --version`) and steps to reproduce. We will respond as soon as we reasonably can. Do not post vulnerabilities in public issues before we have had a chance to fix them.

This tool is read-only against Active Directory. If you find a case where it changes a directory object, treat it as a security bug and report it.
